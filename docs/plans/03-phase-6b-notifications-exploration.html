2. Detailed Design Proposals & Characteristics

Design A: Slab Flyout & Compact Toasts

Recommended

Minimalist & Faithful to Phase 6a. A clean dropdown panel anchored under the bar's notification button with floating 320px toast popups.

  • Toast styling: Lightweight cards with 2px lavender countdown timer and subtle border glow on critical urgency.
  • Drawer anatomy: 340px width, single chronological stream with app badges and direct dismissal.
  • Bar integration: Bell icon with pill badge when count > 0, muted slashed bell in DND mode.
  • Complexity: Low footprint, pure QML PopupWindow + PanelWindow.

Design B: Power User Action Center

Rich Features

Rich Interactive Hub. Grouped notifications by application with inline quick-replies, action buttons, and media preview thumbnails.

  • Toast styling: Expands on hover to reveal rich action buttons ("Reply", "Mark Read", "Open in Browser").
  • Drawer anatomy: 380px full-height edge panel with collapsible per-app accordions and bulk app clearing.
  • Inline Input: Built-in text field for instant Matrix / Discord / Email replies without focusing the app.
  • Complexity: Moderate, requires action invocation bridge over DBus.

Design C: HUD Floating Island

Experimental

Keyboard-Driven Island Overlay. Floating centered/top pill that expands dynamically, with tab filters (All, Mentions, System).

  • Toast styling: Pill OSD centered at top-right, stacking with dynamic scale perspective.
  • Drawer anatomy: Centered HUD overlay with category chips and vim-like keyboard shortcuts (d to dismiss, c to clear).
  • Focus model: Captures transient keyboard navigation for instant triage.
  • Complexity: Higher, requires keyboard grab & focus management.
