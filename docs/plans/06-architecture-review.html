Full codebase architecture review

This review covers the whole shell at 97093ac: bar, modules, panels, services, helpers, tests, and docs. I read every QML file, the Python helpers, the lint gates, and the calendar tickets. The layering is sound. I ordered the findings below by effect on daily use, each with its files and the check that closes it.

  • Shell root builds one slab bar per screen and owns the three floating windows. It imports no services directly.
  • Modules and windows are thin views. Modules extend ModuleBox. Both centers extend PanelShell and read one service each.
  • Services hold the mutable state. CalendarService, NotificationServer, MprisPlayers, and CavaService expose models and visibility flags. QML never touches the network directly.
  • Helpers and backends do the polling. calendar-fetch.py writes the cache file. calendar-clock.py prints zone times to stdout for the collector. QML reads the cache through FileView.

Read order, left to right. Shell passes screen and anchor down. Services push state up. Clock and the bell close each other through the other service. Toast popups read both services, and tray shares focus logic with the notification server.

F3. Hidden calendar repoll can use stale args		 setCalendarHidden mutates the list then repolls in the same tick. Hide then show returns the right set on first poll.

F4. Own writes trigger extra polls		 Hidden and zone FileViews reload on their own setText and assign a new array each time, which queues another poll. services/CalendarService.qml idHiddenFile, idZonesFile Compare before assign and skip when equal. Saving zones causes zero extra polls in the log.
Medium
F5. Cache reload rebuilds the grid		 Each cache reload parses to a new object, which invalidates the 42 cell grid and agenda even when days are unchanged. services/CalendarService.qml parseEventsCache, monthCells Add a dirty check on file content. Rapid reloads keep the grid stable.
Low
F6. Empty collector hides errors		 The code attaches the events collector but leaves it empty. Failures surface only as exit codes, and the code drops helper stderr. services/CalendarService.qml idEventsCollector Stream stderr to the log or remove the collector. A failed fetch names its cause.

F7. State dir race is silent		 mkdir -p runs at the same time as FileViews on paths that may not exist. First load failures print nothing. services/CalendarService.qml idZonesDirProcess Order dir creation before first read or log the miss. Cold start with no state dir loads defaults cleanly.

Risks

  • Coupled closers. Two panels enforce one open panel by writing to each other. A third panel triples the links. A shared closer removes the mesh.
  • All or nothing polls. One dead calendar fails the whole 15 minute poll by design. Hiding the calendar is the escape hatch. Per calendar isolation stays out of scope until users ask.
  • Focus is best effort. Outside click always dismisses. Escape needs panel focus. Fast re toggle inside 300 ms can swallow the open. Tests should encode this limit.
  • Cache loss looks like no data. The stale marker covers failed polls. It does not cover a wiped cache dir. State dir storage or a startup seed closes the gap.
