Problem: one module owns events, world clock, denylist, anchor state, and path helpers, so every Agenda change wades through zone-timer wiring.

Solution: hide CalendarEvents and WorldClock behind the existing CalendarService seam; call sites keep binding to the same interface.

  • locality: event bugs stop sharing a file with zone wiring
  • leverage: hottest file gets safe to change
  • pure date math becomes import-testable
  • interface unchanged; no caller churn
