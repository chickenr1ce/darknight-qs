Risks

  • Role drift. Generated roles may not cover every bar token. The frozen map bounds this.
  • Private API. The idle type name may shift between releases. Check at build time.
  • Focus fights. Two floating panels contest grabs. One open at a time or a shared closer.

Open questions

  • Q1. Which generated roles drive which Colors.qml tokens?
  • Q2. Where does the switcher live? Module, powermenu, or keybind.
  • Q3. Which weather provider and interval? Must survive offline and rate limits.
  • Q4. Answered. Secret iCal URL plus curl first, gcalcli optional, one fetch per calendar. Month grid renders from local cache.
