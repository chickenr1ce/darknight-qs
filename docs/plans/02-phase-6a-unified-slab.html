Phase 6a
Unified Slab Restyle

Decisions from the grilling session, frozen. The bar abandons waybar's floating-module look: one full-width surface ("slab") on which modules become invisible regions, revealed by hover, animated with a soft motion vocabulary, and unified under a single hero element.

● Approved 2026-08-23 ● Implemented 2026-08-24 · commit b8c59fe (phase-6a) Pure QML · Tier ≤ 2 · no compiled code

Decisions — grilling session, all settled

#DecisionCall
D-01Unification conceptOne full-width slab. Modules lose their own backgrounds and become transparent hit-regions on the shared surface.
D-02Hover treatmentPill tint shift to background-secondary (inset 2px) + 2px lavender underline expanding symmetrically from center with smooth opacity fade.
D-03Click feedbackPress-scale ≈0.97 + release brightness pulse. In Workspaces and Tray, only the clicked pill/icon scales — never the whole module.
D-04Hero elementHero gradient rejected: Animated gradient on active pill tested and removed (unreadable/tacky); active workspace pill uses solid Colors.backgroundSecondary + lavender text.
D-05Hero ownershipRevisit hero slot ownership if/when the audio visualizer lands (migration plan Phase 7).
D-06Slab placement & radiusFloating: 4px top offset, 12px side insets (Globals.horizontalBarMargin), slabRadius: 9 on outer corners (pills keep radius: 5).
D-07Region separationCluster hairlines: 2px vertical dividers at 50% opacity flanking the center ActiveWindow region only, with collision/empty guards. No dividers between individual modules.
D-08Motion personalitySnappy & Soft: 140ms hover / 120ms press transitions.
D-09SequencingRestyle lands first as Phase 6a; new-module work (migration plan Phase 7) then builds against the final chassis. Native Notifications swap remains independent.
D-10DP-2 parityInherits automatically — restyle lives in shell chrome / ModuleBox, both outputs get it with zero branching.

Resulting anatomy

PanelWindow (transparent, floating geometry unchanged)
└── slab Rectangle                      ← Colors.background, slabRadius 9, fills bar area
    ├── hairline │ ← left cluster          ← 2px rect, opacity 50%, with cluster collision guard
    ├── RowLayout … Clock · Workspaces     ← regions: transparent until hover (pillInset 2px)
    ├── hairline │                          ← flanks center only (D-07)
    ├── ActiveWindow (anchored true-center) ← keeps independent center anchoring
    ├── hairline │
    └── RowLayout … Media · Cpu · Audio · Notifications · Tray · PowerMenu
  • Regions keep hit-testing: each former ModuleBox still measures its own width (implicitWidth contract intact), draws nothing at rest, paints pill tint + centered underline on hover, scales/pulses on press.
  • ActiveWindow stays anchored to the PanelWindow's horizontal center — slab must not change its centering math.
  • Hairlines are layout children of the slab, not region decorations, so they never participate in hover.

Implementation outline — file by file

  • config/Globals.qml — motion tokens: hoverMs: 140, pressMs: 120, slabRadius: 9; press-scale tokens (pressScaleModule: 0.94, pressScalePill: 0.86) and slabInset derived from horizontalBarMargin + slabEdgePadding so slab geometry lives in one place.
  • components/ModuleBox.qml — root color: "transparent"; pill-shaped hover tint (2px inset), centered expanding underline with opacity fade, HoverHandler non-blocking hover detection, press-scale + pulse.
  • components/PressFeedback.qml + components/PressScale.qml — shared feedback components: release pulse + underline, and the press-squash driver (OutQuad press / OutBack release), so every clickable surface shares one timing/easing shape.
  • modules/Workspaces.qml — per-pill press scale (D-03), solid secondary background for active workspace button.
  • modules/Tray.qml — per-icon press scale via the shared PressScale driver.
  • modules/Media.qml — unified to transparent slab background with text-color play/pause state.
  • shell.qml — slab Rectangle (radius 9) behind idBarLayout; 2px hairlines flanking center with collision guards against side clusters.
  • No C++/Go — every effect maps to QML property transitions, Behavior on, or declarative property bindings.
  • Consistent visual vocabulary: pill geometry matches between module hover and workspace/tray buttons.
  • Ground rule applies: this departs from waybar parity deliberately and is reconciled below, not in prose.

Deviation log entries (append to ECO-HY3)

  • D13 · Unified slab replaces floating modules. Single Colors.background surface behind all regions (slabRadius: 9); modules transparent at rest (supersedes waybar #module per-box styling translated in Phase 1).
  • D14 · Motion system added. Pill hover tint (inset 2px) + center-expanding lavender underline at 140ms, press-scale + release pulse at 120ms; per-pill/icon scaling in Workspaces and Tray — no waybar counterpart.
  • D15 · Hero element iteration. Animated gradient tested on active workspace pill and rejected as visually noisy; reverted to solid backgroundSecondary with lavender text. Hero ownership deferred to audio visualizer (Phase 7).
  • D16 · Hairlines & Media refinement. Hairlines upgraded to 2px @ 50% opacity with dynamic collision guards to prevent module overlap; Media module unified to transparent slab with text-color playback indication.

Acceptance criteria

  • A1 — Bar reads as one continuous surface; no module has its own visible background at rest.
  • A2 — Hovering any region shows pill tint + centered expanding underline within the 140ms budget; leaving reverses smoothly. Workspaces & Tray modules receive hover correctly.
  • A3 — Pressing a module squashes only that region; release pulses. In Workspaces and Tray, only the clicked item scales.
  • A4 — Active workspace pill displays clean solid secondary background with lavender text; urgent-red and inactive states remain distinct.
  • A5 — 2px hairlines flank the center region only, hiding when center is empty or if clusters would collide. ActiveWindow remains pixel-centered regardless of cluster widths.
  • A6 — DP-2 shows the identical treatment on its minimal set with no extra config.
  • A7 — No QML errors on load/hotplug; frame cost imperceptible.
