# darknight theme credits

The `darknight` palette came from this repository's own `config/Colors.qml`
fallback. The two background images are third-party artwork: all rights
remain with the artists, no license is granted, and the credit below is a
courtesy. The repository [NOTICE](../../../NOTICE) holds the canonical
third-party notice.

This file lives in the repository only. `scripts/seed-themes.sh` copies
`colors.toml`, `light.mode`, and `backgrounds/`, so a theme seeded into
`~/.local/share/quickshell/themes/darknight/` does not include it.
