# quickshell

Quickshell bar and desktop shell (QML) for my personal pc.

![bar](assets/bar.png)

Clock, workspaces, tray, active window, cava, media, audio, notifications, power menu. One bar per monitor, full modules on DP-1.

Clock opens the calendar panel, cava bars open the cava tuner. Panels open under their trigger on the clicked monitor.

Run with `quickshell`.
